# Chapter 02 & Chapter 03

Chapter02_03.html을 열면 모든 본문·그림·수식을 인터넷 없이 읽을 수 있습니다. Chapter02_03.md는 편집용 원고이며 assets 폴더와 함께 보관합니다.

실행: python -m pip install -r requirements.txt
이어서: python chapter02_03_examples.py

기업 200개사와 FDS는 모두 합성 데이터입니다. 기업 스냅샷 200행, 패널 2400행, FDS 학습/검증/평가 각각 100000행이 포함됩니다. 임곗값은 검증 데이터로 선택했고 최종 평가로 재선택하지 않았습니다.

전체 코드가 본문과 부록에도 수록되어 있습니다. 파라미터 변경 후 다시 실행하면 CSV와 그림이 갱신됩니다. 원고 및 HTML의 설명·결과표는 자동 갱신되지 않으므로 함께 수정해야 합니다. 이후 장은 장별 폴더와 그림 번호로 추가합니다.
