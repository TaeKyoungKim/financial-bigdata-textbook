1.1 규칙 기반 시스템의 한계와 금융 조합 폭발

1.1.1 금융 비즈니스와 이론

규칙 기반 시스템은 사람이 결정 조건을 명시한다. 예를 들어 금리·환율·수급에 임계값을 정하고 조건이 맞으면 포지션을 보유한다. 조건이 단순하고 책임 소재가 분명해야 하는 업무에서는 유용하다. 주문 한도, 거래 금지 종목, 손실 제한과 같은 통제도 규칙으로 구현할 수 있다.

문제는 모든 시장 상태를 예외 규칙으로 설명하려 할 때 생긴다. 변수와 구간이 늘어나면 검토할 조합이 급증한다. 같은 수급 신호라도 시장의 유동성이나 참여자가 바뀌면 미래 수익률과의 관계가 달라질 수 있다. 이런 관계 변화는 규칙 기반 시스템뿐 아니라 학습된 모델에도 영향을 준다. 머신러닝은 자동 적응을 보장하는 대체품이 아니라 관계를 추정하고 갱신할 수 있는 도구다.

1.1.3 재현 가능한 실습

신호 xₜ는 t일 종료 후 관측하며, t+1일 수익률에 적용한다. 거래비용은 포지션 변화량에 비례하는 단순 가정이다. 단순 수익률을 사용하므로 자산은 (1 + 전략 수익률)의 누적곱으로 계산한다. 현금 이자와 최종 청산 비용은 생략했다. 현실의 실행 가격과 거래 시점은 별도로 모델링해야 한다.

import numpy as np
import pandas as pd

def regime_example(n=1000, seed=42, cost=0.0003):
    """Known signal flips sign halfway; this is an assumed scenario."""
    rng = np.random.default_rng(seed)
    x = rng.normal(size=n)
    beta = np.where(np.arange(n) < n // 2, 0.003, -0.003)
    # x[t-1] predicts return[t]; x[t] only becomes available after return[t].
    lag_x = np.r_[0.0, x[:-1]]
    asset_return = beta * lag_x + rng.normal(0, 0.012, n)
    signal = (x > 0).astype(float)
    held = np.r_[0.0, signal[:-1]]
    turnover = np.abs(np.diff(np.r_[0.0, held]))
    net = held * asset_return - cost * turnover
    equity = np.r_[1.0, np.cumprod(1 + net)]
    peak = np.maximum.accumulate(equity)
    drawdown = equity / peak - 1
    return pd.DataFrame({'return': asset_return, 'signal': signal,
                         'held': held, 'net': net}), equity, drawdown

market, equity, drawdown = regime_example()
regime_result = {}
for name, sample in [('전반', market.iloc[:500]), ('후반', market.iloc[500:])]:
    wealth = np.r_[1, np.cumprod(1 + sample['net'])]
    regime_result[name] = {'누적수익률': float(wealth[-1] - 1),
        '최대낙폭': float(-(wealth / np.maximum.accumulate(wealth) - 1).min())}

후반의 성과 변화는 이 데이터 생성 과정의 결과다. 이것만으로 모든 규칙 기반 전략이 실패하거나 머신러닝이 우월하다고 결론 내릴 수 없다. 비교하려면 같은 데이터, 같은 비용, 같은 위험 제약에서 학습 모델과 기준 전략을 평가해야 한다.

최대낙폭은 각 시점 자산을 그때까지의 고점으로 나눈 값에서 계산한다. 위 표의 낙폭은 구간별 초기자산을 1로 놓고 계산했다.

로그 수익률에 포지션을 곱한 뒤 지수화하는 방식은 일반적인 레버리지·현금 혼합 포트폴리오의 정확한 회계식이 아니다. 자산 로그 수익률이 rₜ라면 먼저 단순 수익률 exp(rₜ)−1로 바꾸어 포지션과 비용을 적용한다.

1.2 전문가 시스템에서 데이터 주도형 퀀트로

1.2.1 금융 비즈니스와 이론

규칙 기반 접근은 사람이 관계를 정하고, 학습 기반 접근은 데이터를 사용해 관계의 파라미터를 추정한다. 실제 운용 시스템은 두 방법을 함께 쓸 수 있다. 예측은 모델이 담당하고 주문 크기와 허용 자산은 규칙이 제한하는 방식이다.

데이터 주도형 연구의 핵심은 특정 유명 펀드의 비공개 전략을 재현하는 데 있지 않다. 작은 통계적 관계가 새로운 표본에서도 유지되는지, 거래비용을 넘는지, 충분히 독립적인 기회가 있는지를 검증하는 데 있다. 초안의 특정 펀드 승률과 무위험 수렴 주장은 확인 가능한 근거가 없어 일반적인 가정 실험으로 대체했다.

1.3 금융 머신러닝의 세 가지 난제

1.3.1 낮은 신호대잡음비와 과적합

예측 가능한 부분보다 예측 불가능한 변동이 큰 문제에서는 훈련 성능이 쉽게 과장된다. 그러나 금융 데이터 전체의 잡음 비율을 하나의 고정 숫자로 제시할 수는 없다. 자산, 기간, 타깃과 정보 집합에 따라 달라지기 때문이다.

독립 잡음과 제곱오차를 가정하면, 고정된 입력에서 학습 표본에 대한 평균 예측 오차는 편향의 제곱, 추정량의 분산, 잡음 분산으로 분해된다.

이 식은 모델이 복잡할수록 언제나 실패한다는 법칙이 아니다. 모델의 용량과 표본 수를 고려해 검증해야 한다는 근거다. 정규화와 단순 기준 모형은 유용한 출발점이지만 좋은 데이터와 올바른 평가를 대신하지 않는다.

쉽게 이해하면

신호대잡음비(SNR)는 라디오 주파수를 맞출 때 방송 소리(신호)가 지지직거리는 잡음보다 얼마나 큰지를 뜻한다. 주가 데이터는 잡음이 신호보다 훨씬 큰 경우가 많아서, 모델이 잡음까지 ‘패턴’으로 착각해 외워버리기 쉽다(과적합). 편향-분산 분해는 예측이 틀리는 이유를 두 가지로 나눈다 — ① 모델이 너무 단순해서 애초에 못 맞히는 경우(편향), ② 모델이 데이터 하나하나에 너무 민감하게 반응해 조금만 데이터가 바뀌어도 결과가 요동치는 경우(분산). 다트를 던질 때 항상 과녁 왼쪽으로 쏠리면 편향이 크고, 매번 맞는 위치가 들쭉날쭉하면 분산이 큰 것과 같다.

과거 이동평균을 ‘진짜 신호’로 놓고 잔차 분산과 비교하는 것만으로 실제 예측 SNR을 알 수는 없다. 이동평균도 잡음에서 만들어질 수 있다. 이번 실습에서는 생성 과정이 알려진 별도의 신호와 잡음에 대해서만 이론적 SNR을 계산한다.

1.3.2 비정상성과 ADF 검정

약정상 시계열은 평균과 유한한 분산이 시간에 따라 같고, 공분산이 시점 자체가 아닌 시차에만 의존한다. 가격 수준에는 추세나 단위근이 나타날 수 있으며, 수익률로 바꾸더라도 변동성 군집과 구조 변화가 남을 수 있다.

AR(1) 모형 yₜ=ρyₜ₋₁+εₜ에서 차분하면 Δyₜ=(ρ−1)yₜ₋₁+εₜ가 된다. ADF 검정은 여기에 상수·추세와 과거 차분을 추가해 단위근 귀무가설을 검정한다.

단위근 귀무가설은 δ=0이다. 단순 AR(1)의 정상 조건은 |ρ|<1이며 δ<0만으로 이 조건과 동치가 되지는 않는다. ADF 통계량은 일반적인 t 분포를 따르지 않는다. 임계값과 p값은 상수·추세 설정, 표본 수 등과 함께 해석한다.

실습은 상수만 포함하는 설정을 사용한다. 작은 p값은 그 설정에서 단위근 가설을 기각하는 근거이며, 모든 형태의 정상성이나 수익률의 예측 가능성을 증명하지 않는다. 큰 p값도 단위근이 확정되었다는 뜻은 아니다. 참고: statsmodels ADF 문서.

쉽게 이해하면

‘정상성(stationarity)’이 있다는 건 시간이 지나도 평균이나 변동성 같은 통계적 성질이 크게 바뀌지 않는다는 뜻이다. 반대로 주가 ‘수준’(5만원, 10만원 등)은 계속 오르내리며 추세를 타서 정상성이 없는 경우가 많다. 그래서 가격 자체보다 ‘수익률(변화율)’을 분석 대상으로 삼는 경우가 많다. ADF 검정은 ‘이 시계열이 정상성이 없다(추세를 따라 계속 흘러간다)’는 가설을 통계적으로 기각할 수 있는지 확인하는 도구라고 이해하면 된다 — ‘이 동전은 편향되지 않았다’는 가설을 데이터로 검증하는 것과 비슷한 절차다.

그림 1-3. 이 합성 자료는 독립적인 로그 증분을 누적해 만들었다. 차분이 안정적으로 보이는 것은 생성 가정의 결과이며 실제 데이터 전반에 대한 증거가 아니다.

import numpy as np
import pandas as pd
from statsmodels.tsa.stattools import adfuller

def stationarity_example(n=1000, seed=42):
    rng = np.random.default_rng(seed)
    # Zero expected log increment. Differenced series is iid by construction.
    log_return = rng.normal(0, 0.012, n)
    log_price = np.log(100) + np.cumsum(log_return)
    results = []
    for name, series in [('로그 가격', log_price), ('로그 차분', np.diff(log_price))]:
        result = adfuller(series, regression='c', autolag='AIC')
        results.append({'시계열': name, 'ADF': result[0], 'p값': result[1],
                        '시차': result[2], '5%임계값': result[4]['5%']})
    # True signal is known only because we generate it explicitly.
    true_signal = rng.normal(0, 0.001, n)
    noise = rng.normal(0, 0.01, n)
    theoretical_snr = 0.001**2 / 0.01**2
    return log_price, log_return, pd.DataFrame(results), theoretical_snr

log_price, log_return, adf_table, snr = stationarity_example()

그림 1-4. 분할 전 가격에 0.5를 곱하면 가격 단위가 연결된다. 오른쪽은 분할 주변 로그 수익률이며, 보정 후에는 인위적인 약 −0.693의 단층이 사라진다.

1.4.3 재현 가능한 실습

import numpy as np
import pandas as pd

def financial_pipeline(n=500, window=20, horizon=5, seed=42):
    if n <= window + horizon or window < 2 or horizon < 1:
        raise ValueError('n, window, horizon의 범위를 확인하세요.')
    rng = np.random.default_rng(seed)
    dates = pd.bdate_range('2023-01-02', periods=n)
    increments = rng.normal((0.10 - 0.5 * 0.25**2) / 252, 0.25 / np.sqrt(252), n)
    base = 50000 * np.exp(np.cumsum(increments))
    raw = base.copy()
    split_day = n // 2
    raw[split_day:] *= 0.5
    df = pd.DataFrame({'raw_close': raw, 'split_factor': 1.0}, index=dates)
    df.iloc[split_day, df.columns.get_loc('split_factor')] = 0.5
    # Event-day close is already post-split; apply only strictly future factors.
    factors = df['split_factor'].shift(-1, fill_value=1)
    df['adjustment'] = factors.iloc[::-1].cumprod().iloc[::-1]
    df['adj_close'] = df['raw_close'] * df['adjustment']
    df['log_return'] = np.log(df['adj_close']).diff()
    df['vol_20d'] = df['log_return'].rolling(window).std(ddof=1) * np.sqrt(252)
    df['momentum_20d'] = df['log_return'].rolling(window).sum()
    df['target_fwd5d'] = np.log(df['adj_close'].shift(-horizon) / df['adj_close'])
    # Preserve unavailable labels instead of turning them into class 0.
    df['target_class'] = (df['target_fwd5d'] > 0).astype('Int64')
    df.loc[df['target_fwd5d'].isna(), 'target_class'] = pd.NA
    features = ['vol_20d', 'momentum_20d']
    training = df.dropna(subset=features + ['target_fwd5d']).copy()
    inference = df.dropna(subset=features).copy()
    assert np.allclose(df['adj_close'], base * 0.5)
    assert np.isclose(df['log_return'].iloc[split_day], increments[split_day])
    assert len(training) == n - window - horizon
    assert df['target_class'].tail(horizon).isna().all()
    return df, training, inference, features

학습용 데이터는 475행 × 9열, 피처 행렬 X는 475행 × 2열이다. 최신 추론용 피처는 480행에 존재한다. 분할 보정의 연속성, 분할일 수익률, 학습 행 수, 마지막 타깃의 결측 보존을 코드의 검증문으로 확인했다.

피처는 20개의 수익률을 요구하므로 첫 20개 행을 사용할 수 없다. 학습용 데이터에서는 마지막 5개 행의 미래 타깃도 아직 알 수 없다. 따라서 500−20−5=475행이 남는다. 다만 실제 추론에서는 마지막 5개 행도 유효한 입력이다. 타깃이 없다는 이유로 최신 피처까지 버리면 안 된다.

현재까지 알려진 분할을 이용한 수정주가라도 과거 시점의 절대 가격 수준은 나중에 바뀔 수 있다. 실전 연구에서는 공급자의 수정 이력과 당시 사용 가능한 자료를 확인한다. 이 실습의 보정은 단위 연속성을 검증하는 예이며, 그 자체로 모든 시점 정보 관리가 해결되었다는 의미는 아니다.

1.5 시간 순서를 지키는 학습·검증 설계

그림 1-5. 위쪽은 한 샘플의 피처·미래 타깃 관계, 아래쪽은 학습·검증 경계의 개념도다. 두 줄은 같은 축척이 아니며 실제 경계는 타임스탬프로 계산한다.

20일 모멘텀과 변동성은 t일까지의 데이터로 계산한다. 종가를 모두 확인한 후 신호를 만드는 경우 t일 종가에 그대로 체결되었다고 가정하지 않는다. 다음 거래 시점의 실행 가격과 비용을 정하고, 실제 거래 수익률 타깃은 그 정의에 맞추어 별도로 만든다. 이 장의 종가-종가 타깃은 예측 문제를 정의하기 위한 교육용 값이다.

분할은 과거 학습, 그 뒤 검증, 마지막 평가 구간 순서로 진행한다. h=5인 라벨을 사용한다면 학습의 마지막 샘플들이 검증 구간 가격을 포함할 수 있다. 예를 들어 첫 검증 입력이 관측일 300이면, 엄격한 비중첩 기준에서는 학습 라벨의 종료일 t+5가 300보다 앞서야 한다. 이 기준에서는 학습 입력의 마지막 날짜가 294다.

일정 간격의 단일 시계열에서는 5행의 간격으로 이를 구현할 수 있지만, 결측일과 여러 종목이 섞이면 행 개수만으로 처리하지 않는다. 각 라벨의 시작·종료 시각을 검사한다. 여러 검증 블록을 쓰는 설계에서는 중첩 라벨 제거와 추가 완충 구간의 필요성을 별도로 결정한다.

모델의 정확도와 전략의 수익률도 구분한다. 상승 빈도가 높은 데이터에서 항상 상승을 예측하는 분류기가 높은 정확도를 낼 수 있다. 반대로 작은 오차 개선이 거래비용을 넘는 경제적 개선을 만들지 못할 수도 있다. 다음 장에서는 기준 모형과 동일한 시계열 분할을 사용해 이 차이를 확인한다.

1.7 장 요약과 확인 문제

규칙은 명시적인 통제에, 학습은 데이터 관계 추정에 활용할 수 있다. 금융 연구에서는 작은 통계적 우위가 비용 후에도 남는지 확인하고, 시간 순서와 당시 이용 가능한 정보를 유지해야 한다. 데이터 변환은 수식과 코드가 일치해야 하며, 성과 수치는 실행한 결과로만 보고해야 한다.

확인 문제

  1. 5개 변수를 각각 4구간으로 나누면 가능한 상태 수는 얼마인가? 이것이 모든 모델의 필수 학습 표본 수인가?
  2. 승률 50.8%, 이익·손실 크기 0.15%인 거래의 비용 전 기대손익은 몇 bps인가?
  3. ADF p값이 0.01이면 수익률의 예측 가능성이 증명되는가?
  4. 1주가 2주가 되는 분할에서 과거 가격에는 어떤 계수를 적용하는가? 분할 당일도 보정하는가?
  5. 왜 최신 5일 데이터가 학습에서는 빠지지만 추론에서는 남을 수 있는가?
  6. 현재 시점의 우량 종목 목록으로 10년 전 전략을 검증하면 어떤 편향이 생길 수 있는가?

해설

  1. 4⁵=1,024개다. 이는 격자 상태 수이며 모든 모델의 보편적 표본 수 하한이 아니다.
  2. (2×0.508−1)×0.0015×10,000=0.24bps다.
  3. 아니다. 해당 설정에서 단위근 귀무가설을 기각하는 근거다.
  4. 과거 가격에 0.5를 곱한다. 이미 분할 후 기준인 당일 종가는 다시 보정하지 않는다.
  5. 과거 기반 피처는 존재하지만 미래 실현 타깃이 아직 없기 때문이다.
  6. 사라진 기업을 누락하는 생존편향과 당시 구성 종목 정보를 무시하는 문제가 생길 수 있다.
